# AMBG_TRAINER

Entity hallucination detection and authenticity scoring for LLMs.

---

## Overview

AMBG_TRAINER is a modular NLP research project designed to detect hallucinated entities generated by Large Language Models (LLMs). The system generates sentences using a local LLM, extracts named entities, validates whether those entities exist in public knowledge sources, and computes an entity authenticity score.

The project focuses specifically on **entity-level hallucination detection**, not factual correctness of entire sentences.

Example:

> "Bill Gates founded Apple in France."

Even though the sentence itself is factually incorrect, all entities are real:

- Bill Gates ✅
- Apple ✅
- France ✅

Therefore:

```text
Entity Authenticity Score = 1.0
```

---

# Features

- Local LLM generation using Ollama + Llama 3
- Named Entity Recognition (NER) using spaCy
- Entity existence validation using Wikipedia
- Hallucinated entity detection
- Entity authenticity scoring
- Batch sentence generation
- JSON dataset generation
- Entity cache system
- UNKNOWN state handling for failed validations
- Modular NLP pipeline architecture

# Entity Authenticity Score

The project computes entity realism using:

\[
entity\_authenticity\_score =
\frac{verified\_real\_entities}
{successfully\_validated\_entities}
\]

---

## Interpretation

| Score | Meaning |
|------|------|
| 1.0 | all entities verified real |
| 0.7 – 0.9 | mostly grounded entities |
| 0.4 – 0.7 | mixed real and hallucinated entities |
| 0.1 – 0.4 | heavily hallucinated |
| 0.0 | all validated entities are hallucinated |

---

# Important Note

This project measures:

- entity realism
- entity grounding
- hallucinated entity density

This project does NOT currently measure:

- factual correctness
- sentence truthfulness
- relation correctness

Example:

> "Bill Gates founded Apple."

All entities are real even though the sentence is false.

# Cache System

The project includes an entity cache system to:

- reduce repeated API calls
- improve speed
- avoid rate limiting
- reuse previously validated entities

Cached entities are stored in:

```text
datasets/entity_cache.json
```

---

# Validation States

Each entity can have one of three validation states:

| State | Meaning |
|------|------|
| TRUE | verified real entity |
| FALSE | verified hallucinated entity |
| UNKNOWN | validation failed |

UNKNOWN entities do not affect authenticity scoring.

---

# Current Limitations

The system currently detects:

- hallucinated entities
- fictional organizations
- invented people
- synthetic locations

The system currently does NOT detect:

- incorrect relationships
- factual inaccuracies
- semantic contradictions
- claim verification
